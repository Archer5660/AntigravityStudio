# Platform icons

The macOS Swift app uses `AppIcon.icon`. Windows uses the separate Pixelmator Pro artwork in `assets/platform-icons/antigravitystudio-windows.ico`; Linux uses its own Pixelmator Pro export at `assets/platform-icons/antigravitystudio-linux.png`. The SVG source files are kept next to those exports. The macOS icon is not used for Windows or Linux packaging.
